# Éditeur TEI

Application de bureau (PySide6, lxml) pour produire et éditer du XML-TEI P5.

Voir `docs/ROADMAP.md` pour le projet complet, `docs/DECISIONS.md` pour les choix d'architecture, et `CLAUDE.md` pour les règles de travail.

## Développement

```
pip install -e ".[dev]"
pytest
python -m tei_editor.app
```
